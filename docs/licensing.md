# Licensing

Status September 3, 2026, the day the repository went public. The code is Apache-2.0 (`LICENSE` at the root); our own documents, figures and captures are CC BY 4.0. The table records each third-party item, what was found, and what was done.

| Item | Situation | Options |
|---|---|---|
| Project code | Apache-2.0, `LICENSE` at the repository root, decided September 3. It carries a patent grant and matches Shaka's licence. | Done. |
| Vega Shaka glue (`ShakaPlayer.ts`, `PlayerInterface.ts`, `polyfills/*.ts`) | Found September 3: these come from `shaka-rel-v4.8.5-r1.2.tar.gz`, which Amazon publishes inside AmazonAppDev/vega-video-sample under MIT-0; the tarball contains no LICENSE.TXT, so the header's reference points at a file Amazon never shipped, and the repository licence is the only licence text that accompanies the files. Amazon's sample does not commit them either: it regenerates them at `npm install`. | Done: the eight files are no longer committed; `tools/shaka/fetch-glue.sh` (run by `postinstall` when they are missing) fetches Amazon's tarball and copies them, then `apply-sightline-changes.py` applies our one change. The public history starts on September 3 with a single commit, so the files appear in no public commit. Still open: a one-line ask to Amazon developer support whether the header is stale, which would let the files be committed like any MIT-0 code. |
| Compiled Shaka bundle (`shakaplayer/dist`) | Shaka Player 4.8.5, Apache-2.0, built with Amazon's Vega patches (MIT-0). No Amazon header. Notices in `apps/vega-player/src/w3cmedia/LICENSE-THIRD-PARTY.md`. | Keep committed. |
| Roboto Flex (static instances in `apps/vega-player/assets/fonts`) | SIL Open Font License 1.1; `OFL.txt` now ships beside the files. The instances were generated with fontTools; the OFL permits this, and the Reserved Font Name is not used in modified names. | Nothing further, but keep OFL.txt with any redistribution. |
| Caption with Intention design system PDF, After Effects project, reference clip | "All Rights Reserved" on the PDF; the site offers them as a free design system. They are not in the repository (scratchpad only). Our implementation follows the published rules and cites them. | Keep them out of the repository. Ask the Chicago Hearing Society whether the runtime may describe itself as implementing Caption with Intention; do not use their name or mark as ours. |
| Tears of Steel excerpts, in the app and in the demo video | CC BY 3.0, Blender Foundation (confirmed 3 September against the Wikimedia Commons record of the official release: share, remix and commercial use permitted with credit, a link to the licence, and an indication that changes were made). Blender additionally asks that anyone *showing the film* keeps the credit scroll; we show a 48-second excerpt inside a demo, not the film. | Done: the About screen credits it, and the video's closing card names the work, the author, the year, mango.blender.org, the licence with its URL, and says the footage was excerpted and shown with captions added. Practical risk for the submission: YouTube Content ID may match the excerpt against Blender's own upload. That is not a licence problem; if a claim appears, dispute it citing CC BY 3.0, and say in the video description that the footage is CC BY 3.0. |
| Media we create (The Envelope, micro-scenes) | Not yet shot. | CC BY 4.0 was the working intention; decide before the shoot so releases match. |
| Third-party models used offline (WhisperX, wav2vec2, PANNs, YuNet) | Used as tools; outputs are data. Their weights are not in the repository. | Nothing further for the runtime; note licences in docs/authoring.md if the tools are redistributed. |
